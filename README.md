# Первый оффер

Статический лендинг школы тестирования: программа Full Stack QA, команда, отзывы и форматы обучения. Кнопки заявки ведут в Telegram: https://t.me/itcore1.

## Локальный просмотр

Из корня репозитория:

```sh
python3 -m http.server 8000
```

Откройте http://localhost:8000. Установка зависимостей и сборка не нужны.

## GitHub Pages

После слияния в main выберите Settings → Pages → Deploy from a branch → main → / (root). Файл `.nojekyll` отключает обработку Jekyll. Изображения, видео и шрифты находятся в `assets/`, пути относительные.

## Цены и акции

Настройки находятся в JSON-блоке `promo-config` в `index.html`. Стоимость группы и индивидуальной программы берётся из `salePrice`; скидка за полную оплату из `fullPaymentDiscount`.

Таймер показывается только при `enabled: true` и будущей корректной дате `priceRiseAt`. После истечения срока он скрывается, цены автоматически не меняются. Акция на 1 ноября 2026 года отключена.

Тарифы личной работы с Алексеем заданы в `alexeyRates`: стоимость месяца для периодов 1, 3 и 6 месяцев. Переключение периода показывает стоимость месяца и сумму за весь период.
